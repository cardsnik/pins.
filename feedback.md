# Фидбек по проекту pins. (диплом)

## Общее впечатление

В целом проект тянет на дипломную работу. Но есть ощущение, что недотянул по функционалу, можно было наклепать прям много всего. Есть и техническая часть (React, Redux, TypeScript, интеграция с Unsplash), и пользовательский сценарий (лента → детальная страница → избранное → авторизация).

---

## Сильные стороны

### Архитектура (FSD)

- Структура `app / pages / widgets / features / entities / shared` выдержана последовательно.
- Зависимости в целом идут «сверху вниз»: страницы собирают виджеты и фичи, `PinGrid` композирует `PinCard` + `FavoriteButton`.
- Публичные API слайсов через `index.ts` — правильный подход, импорты не лезут во внутренности чужих модулей.

### Стек и инженерная база

- Актуальный стек: React 19, Vite, TypeScript, Redux Toolkit, React Router 7.
- Типизация доменной модели `Pin`, маппер `UnsplashPhoto → Pin` — API отделено от UI.
- Общий `fetchClient`, CSS Modules, design tokens в `:root` — аккуратная база для масштабирования.

### UX и полировка

- Skeleton-состояния, empty states, toast-уведомления — приложение не «ломается» на пустых данных.
- Тёмная/светлая тема с сохранением в `localStorage`, учёт `prefers-color-scheme`.
- i18n (RU/EN) через контекст — для диплома это заметный плюс.
- Анимации (GSAP + Framer Motion) используются осмысленно: появление сетки, hover на карточках, страница пина.
- `SpiderWatcher` на auth-экране — запоминающаяся деталь, показывает внимание к micro-interactions.
- `prefers-reduced-motion` в глобальных стилях — забота о доступности.

## Зоны роста

### Тестирование

- Автотестов нет (unit/integration/e2e). Для диплома достаточно хотя бы нескольких тестов на reducers (`favoritesSlice`, `pinsSlice`) и один на `FavoriteButton` или `PinSearchForm`.

### Авторизация

- Auth — клиентская заглушка: любой email/password пускает в систему, сессия не сохраняется после перезагрузки (в отличие от избранного и темы).
- Нет валидации пароля, нет реального backend или mock-сервиса.

### Непоследовательности в архитектуре

| Что | Сейчас | Замечание |
|-----|--------|-----------|
| Auth state | `entities/user` | По FSD auth ближе к `features/auth/model` |
| Favorites persist | `store.subscribe` в `app/store` | Работает, но срабатывает на любое изменение store; лучше middleware или `redux-persist` |
| PinPage | локальный `useState` + `getPinById` | Лента через Redux, деталь — нет; стоит унифицировать |
| Ошибки в slice | хардкод на русском | При EN-локали сообщения останутся русскими — нужен i18n или коды ошибок |

### Функциональные пробелы

- API поддерживает `page`, но пагинации / infinite scroll нет — лента ограничена 20 пинами.
- Поиск без debounce — каждый submit уходит запрос (приемлемо, но можно улучшить).
